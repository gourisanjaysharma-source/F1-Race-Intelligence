# Formula 1 Race Intelligence Dashboard

## Live Website

**Explore the live project:** [F1 Race Intelligence Dashboard](https://f1-race-intelligence-mhgm.onrender.com/)

## Project Overview

The Formula 1 Race Intelligence Dashboard is a data visualization project designed to analyse Formula 1 driver performance, team rankings, tyre strategies, podium achievements, and race reliability. It uses Tableau Public for interactive visualizations and Flask to integrate the Dashboard and Story into a web application.

## Project Objectives

- Analyse driver performance and rankings.
- Compare Formula 1 team performance.
- Explore tyre compound usage and seasonal trends.
- Analyse driver reliability and race completion rates.
- Visualize podium achievements and Grand Prix locations.
- Present insights through an interactive web interface.

## Run the Project Locally

### Prerequisites

- Python 3 installed.
- Internet connection.
- Project files downloaded to your computer.

### Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### Start the Flask Application

```bash
python app.py
```

Open your browser and visit:

`http://127.0.0.1:5000`

## Live Deployment
