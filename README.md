# F1 Race Intelligence Dashboard + Story

The Story URL is taken from the embed code you supplied:
`https://public.tableau.com/views/f1tableauproject/Formula1RaceIntelligence`

## Run in VS Code
1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `python -m pip install -r requirements.txt` (only if Flask is not already installed).
4. Run `python app.py`.
5. Open http://127.0.0.1:5000.

The Dashboard URL is configured from the previously supplied dashboard URL, converted to Tableau's `/views/...` embedding format. If the dashboard itself does not load, copy its own embed code from Tableau Public and confirm the view name.
